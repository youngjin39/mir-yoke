# Consequential choice memo

Inspired by Q00/ouroboros at 825bc68.

Main may enter this optional advisory decision mode whenever a consequential
choice needs judgment. A stall is not required, and the memo grants no new authority.

1. Put the recommendation first: name the proposed choice and the outcome it
   serves, with the smallest scope on which the owner can decide.
2. State the grounds: goals, constraints, observations and assumptions supporting
   the recommendation. Separate checked facts from uncertain premises.
3. Present the strongest dissent fairly: the best alternative, its advantage,
   and the cost or failure mode the recommendation accepts. Do not manufacture
   consensus or weaken a credible objection to make the choice appear settled.
4. Give observable conditions that would reverse the recommendation. Identify the
   evidence to collect and the decision to revisit if those conditions occur.
5. Ask the owner only for unresolved choices requiring their authority; record an
   authorized decision in the existing project record when one exists. If already
   authorized, Main proceeds within that scope. The memo is not an execution gate.
