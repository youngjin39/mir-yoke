# Bounded application investigation

Inspired by morluto/rea at 9e6c624 (ideas only, no license; wording original).

This opt-in guidance supplies no investigation tools. Define the feature, artifact
identity, permitted operations and expected output before examining implementation.
Use only already-installed, already-authorized tools on owned or permitted artifacts.
Permission to inspect does not authorize launching, modifying or redistributing them.
Never bypass access controls, DRM, encryption or licensing restrictions; protected
or inaccessible evidence stays Unknown. Do not disclose secrets or copy proprietary
code or assets into a reconstruction. Main owns scope and the next action.

Follow the [feature-bounded evidence and reconstruction procedure](references/bounded-investigation.md).
