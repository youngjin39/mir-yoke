# Selective Relation Retrieval compatibility pointer

The canonical SRR guidance is supplied by the independently packaged
`mir-core:selective-relations` skill. Apply that skill when it is available for a task involving a
known anchor and maintained declared relationship evidence.

If the namespaced skill, relation adapter, or graph is absent, continue with ordinary targeted search
and source reading. Do not create a graph, install a tool, or infer relationships to compensate.
