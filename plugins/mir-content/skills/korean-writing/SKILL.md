# 한국어 글쓰기와 문맥 검토

Inspired by bear2u/natural-korean-skills at 2a4f1fc (ideas only, no license; wording original).

독자, 글의 목적, 장르, 전달할 사실과 보존할 말투를 먼저 정합니다. 없는 사실이나
인용은 만들지 않고, 확인이 필요한 부분을 표시합니다. 기본 문장 규칙은
`mir-content:fluent-korean`을 따르고, 일반적인 상투적 표현 편집은
`mir-content:no-ai-slop`을 참고합니다. 두 스킬의 규칙을 다시 나열하지 않습니다.

초안이 있으면 진단, 수정, 재검토 순서로 진행합니다. 메모에서 시작하면 사실과
미확정 내용을 구분하고 개요를 만든 뒤 장르별 완료 기준에 맞춰 초안을 씁니다.
수정 여부와 이유는 문맥으로 판단하며, 작성 점수나 AI 저작 여부를 판정하지 않습니다.

- 초안 검토에는 [문맥에 따른 진단과 수정](references/contextual-revision.md)을 사용합니다.
- 업무 문서에는 [보고와 제안](references/business.md)을 사용합니다.
- 기술 문서에는 [가이드와 운영 절차](references/technical-runbooks.md)를 사용합니다.
- 블로그에는 [설명과 경험 공유](references/blogs.md)를 사용합니다.
- 에세이에는 [관점과 서술](references/essays.md)을 사용합니다.
- 공지에는 [대상과 행동 안내](references/public-notices.md)를 사용합니다.
- 회의록과 발표 자료에는 [결정과 전달](references/minutes-slides.md)을 사용합니다.
