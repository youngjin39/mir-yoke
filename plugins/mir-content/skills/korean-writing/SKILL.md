# 한국어 글쓰기와 문맥 검토

Inspired by bear2u/natural-korean-skills at 2a4f1fc (ideas only, no license; wording original).

독자, 글의 목적, 장르, 전달할 사실과 보존할 말투를 먼저 정합니다. 없는 사실이나
인용은 만들지 않고, 확인이 필요한 부분을 표시합니다. 기본 문장 규칙은
`mir-content:fluent-korean`을 따르고, 일반적인 상투적 표현 편집은
`mir-content:no-ai-slop`을 참고합니다. 한국어에는 빈 요약 결말을 덜고 구체적인 주장을 쓰며 글쓴이의 말투를 지키는 일반 원칙만 적용하고, 영어 단어·패턴 목록은 적용하지 않습니다. 두 스킬의 규칙을 다시 나열하지 않습니다.
산출물에서는 해라체 에세이나 개조식 발표 자료와 목록처럼 장르가 요구하는 문체와 보존할 작성자의 말투를 fluent-korean의 존댓말과 문장 종결 규칙보다 우선하되, 에이전트의 안내 메시지와 기본 산문은 `mir-content:fluent-korean`을 따릅니다.

자격 요건, 마감일, 가격, 법규처럼 시간이 지나면 달라지는 외부 사실은 공식 최신 자료나
사용자가 제공한 최신 자료로 확인한 뒤에만 확정 사실로 쓰고, 출처의 날짜나 버전을 남깁니다.
미확인 항목에는 ‘초안’ 또는 ‘확인 필요’ 표시를 유지합니다.

초안이 있으면 진단 전용과 수정 중 요청에 맞는 방식을 먼저 선택합니다.
진단 전용에서는 원문을 변경하지 않고 발견한 문제의 위치와 우선순위, 이유를 제공합니다.
수정 방식에서는 진단, 수정, 재검토 순서를 따릅니다. 한국어 표현과 문맥의 진단은 이 스킬의 진단 전용 방식을
우선하고, 한국어 AI 상투 표현 탐지만 요청해도 이 진단 전용 방식을 사용합니다.
`mir-content:no-ai-slop`의 Detect는 영어 글에만 사용합니다.
메모에서 시작하면 사실과
미확정 내용을 구분하고 개요를 만든 뒤 장르별 완료 기준에 맞춰 초안을 씁니다.
수정 여부와 이유는 문맥으로 판단하며, 작성 점수나 AI 저작 여부를 판정하지 않습니다.
