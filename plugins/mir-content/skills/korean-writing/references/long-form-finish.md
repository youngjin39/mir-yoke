# 한국어 장문 글 마무리하기

Inspired by bear2u/natural-korean-skills at 2a4f1fc (ideas only, no license; wording original).

Main이 장문 글의 마무리 검토를 요청할 때 선택적으로 참고합니다. 글쓴이의 의도와
말투, 명시한 선호를 보존하고 일률적인 문체를 강요하지 않습니다.

1. 구조를 검토할 때에는 개요와 문단의 첫 문장만 읽습니다. 전개 순서가 목적에 맞는지,
   각 절이 필요한 내용을 담고 있는지, 전환 문장이 절 사이의 관계를 분명히 드러내는지
   확인합니다. 중복 제목이나 빈 제목, 빠진 내용을 표시하고 해당 부분을 추가로
   검토합니다. 읽지 않은 본문을 고치지 않습니다.
2. 발견한 문제를 해결할 때에는 해당 본문을 읽습니다. 임시 문구는 들어갈 내용을
   알 때에만 바꾸거나 삭제하고, 알 수 없으면 필요한 정보를 표시합니다. 약어를 처음
   쓸 때 풀어 설명했는지, 용어를 일관되게 썼는지, 분량과 제목 단계, 인용, 전달 방식이
   요청한 형식에 맞는지 확인합니다.
3. 수정한 글을 글쓴이의 선호와 보존한 사실에 비추어 확인합니다. 의미에 영향을 주는
   변경은 설명하고, 해결하지 못한 사실 확인 질문은 남깁니다. 임의의 글쓰기 점수를
   만들지 말고 기존 장르별 지침에 따라 마무리합니다.
4. 재사용할 문체 프로필은 소유자가 요청한 경우에만 만듭니다. 합의한 독자, 말투,
   용어와 선호하거나 피할 표현의 구체적인 예를 쓰기 권한이 있는 기존 프로젝트 문서나 메모리
   위치에 기록합니다. 글쓴이의 선호를 보존하고 프로필을 의도한 용도에 한정합니다.
   한 번의 수정으로 지속적인 선호를 추정하지 않습니다. 권한이 있는 기존 저장 위치가
   없으면 프로필 제안을 Main에게 전달합니다. 새 저장소를 만들거나 글쓴이의 이전 선택을
   알리지 않고 바꾸지 않습니다.
