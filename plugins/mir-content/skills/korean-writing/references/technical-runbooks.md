# 기술 가이드와 운영 절차

Inspired by bear2u/natural-korean-skills at 2a4f1fc (ideas only, no license; wording original).

## 메모에서 초안으로

1. 따라 할 독자의 숙련도, 대상 버전과 실행 환경을 정합니다.
2. 메모를 확인된 사실, 해석, 미확정 항목으로 나눕니다. 누락된 정보를 문장으로
   채워 넣지 말고 확인 사항으로 남깁니다.
3. 사전 조건, 권한, 순서, 예상 결과, 확인 방법과 실패 시 복구 경로를 배치합니다.
4. 명령과 예시는 검증한 범위를 밝히고, 파괴적인 단계는 영향과 필요한 승인을 설명합니다.
5. 초안을 작성한 뒤 [문맥 검토](contextual-revision.md)로 의미와 말투를 점검합니다.

## 완료 기준

독자가 단계별 성공 여부를 판별하고, 실패하면 중단하거나 복구할 수 있어야 합니다.
미확정 사실과 필요한 확인 사항이 보이고, 독자에게 없는 근거나 약속을 전달하지
않는지 검토합니다. 기준을 충족하지 못한 부분은 완료로 표시하지 않습니다.
