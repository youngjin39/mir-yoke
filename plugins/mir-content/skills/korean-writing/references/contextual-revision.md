# 문맥에 따른 진단과 수정

Inspired by bear2u/natural-korean-skills at 2a4f1fc (ideas only, no license; wording original).

기본 문법과 존댓말은 `mir-content:fluent-korean`에 맡기고, 일반적인 상투어와
문체 편집은 `mir-content:no-ai-slop`을 참고합니다. 여기서는 문맥에 따른 판단을 기록합니다.

1. 진단 전에 독자, 목적, 장르, 사실, 의도한 말투를 확인합니다. 의도가 불명확하면
   추측으로 바꾸지 말고 보존하거나 확인할 질문으로 남깁니다.
2. 아래 단서를 읽는 데 실제로 지장을 주는 부분과 연결합니다. 단서가 있다는 이유만으로
   오류로 판정하지 않습니다. 법적 문구, 용어, 인용과 의도한 반복은 보존할 수 있습니다.
3. 발견한 부분마다 원문 위치, 독자가 겪을 문제, 수정 또는 보존 결정과 이유를 적습니다.
   수정할 때에는 의미, 사실, 인용, 수치와 글쓴이의 관점을 유지합니다.
4. 수정한 문단을 앞뒤 문단과 함께 다시 읽습니다. 전후 결과를 비교하여 해결한 문제,
   보존한 표현, 새로 생긴 문제와 남은 확인 사항을 기록합니다. 필요한 부분만 다시 고칩니다.

| 검토 단서 | 문맥에서 확인할 점 |
| --- | --- |
| 번역투 | 외국어 구조 때문에 행위자나 문장 관계를 이해하기 어려운지 확인합니다. |
| 반복되는 어미 | 정보의 흐름을 가리는지, 의도한 강조나 형식인지 구별합니다. |
| 문체 혼용 | 독자나 화자가 달라진 것인지, 이유 없이 높임 수준이 바뀐 것인지 확인합니다. |
| 추상 명사의 연쇄 | 누가 무엇을 하는지 풀어 써야 독자가 판단할 수 있는지 확인합니다. |
| 모호한 지시 표현 | ‘이것’, ‘해당’, ‘그 부분’이 가리키는 대상을 찾을 수 있는지 확인합니다. |
| 획일적인 리듬 | 문장 길이와 전개가 내용의 중요도나 논리 관계를 드러내는지 확인합니다. |

결과에는 수정한 글과 간단한 전후 기록을 제공합니다. 기록 형식은
‘원문 위치 / 진단 / 수정·보존 / 이유 / 재검토 결과’로 충분합니다.
모든 문장에 설명을 붙이지 말고, 실제로 검토한 발견 사항만 남깁니다.
