# ADR-82 — Product Planes, Capability Packs and Composition (superseded)

This decision proposed product planes and capability-pack composition over the Minimal Starter
boundary it amended. ADR-83 superseded it and defines the Minimal Starter, the standard Project
Agent Kit, the optional installed CLI, the plugin surface, and the inert-reference boundary.

Selected files from this decision are preserved under `reference-templates/advanced-composition/`
for inspection in addition to Git history. They are inert, non-default references and
do not expose an active `yoke` command or adoption path.

The full record is preserved at
`docs/_archive/decisions/adr-82-product-planes-capability-packs-and-composition-historical.md`.
