# Bluebrick: History

## Purpose

Preserve design chronology without allowing old centralization mechanisms to become current
authority.

## Public Interface

The public decision index and `docs/history/centralization/`.

## Rules and Hazards

Do not delete ADR evidence. Current readers follow ADR-83 first; historical executable recovery
uses Git history, not active payload copies.

## Dependencies and Validation

Depends on Contract. Validate with decision-authority and link-integrity tests.
