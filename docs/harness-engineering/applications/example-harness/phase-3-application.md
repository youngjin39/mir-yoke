# Phase 3 — Memory & Context Application — Historical Pointer

This completed ledger recorded a private control-plane repository applying a memory and context phase to itself: memory-entry lifetime
fields, a sliding-window retrieval path, compaction advisory facts, and a session-start helper that injected four upfront items, with
propagation rules making lifetime fields mandatory everywhere and redaction mandatory for personal repositories. The memory store, the
measurement modules and the session hooks it names do not exist in this repository.

Current authority is ADR-83 (the four-file Starter, the Project Agent Kit recipe and the optional installed CLI are the only adoption
layers), ADR-84, which already classifies this whole directory as history, ADR-85 (agent contracts), ADR-86 (Mir Harness maintains this
repository) and ADR-81 (the Starter). Fleet rollout, hash conformance, direct deployment, drift enforcement and notification behaviour are
cancelled and named only to forbid their return; the current replacement guide is `docs/operations/harness-engineering-upgrade.md`.

A new session must not execute the historical procedure. The complete original is preserved in
[the archive](../../../_archive/harness-engineering/applications/example-harness/phase-3-application-2026-06-13-historical.md).
